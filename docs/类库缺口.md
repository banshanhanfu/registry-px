## 重点缺口（高频 + 纯 .px 可行 + 原生底座已具备）

1. **TOTP/HOTP** —— HMAC-SHA1/256 原生已有，几十行可成 —— ✅ 2026-09-24 落地 `totp`（RFC 4226/6238 官方向量双轨 PASS）
4. **datetime 加固** —— ✅ 2026-09-24 追加 weekday/Zeller、ISO8601 解析/格式化、相对时间（148 行，双轨 PASS）
2. **Set / Counter / Trie / 编辑距离 / 自然排序 / slug / 千分位** —— 文本/容器面高频小件
3. **Redis / MQTT 客户端** —— TCP + 明文协议，纯 .px 可写（与 pg/mysql 同档，需真实服务验证）
4. **datetime 太薄**（49 行）—— 对照 Go time / Python datetime / Rust chrono，工作日/ISO8601/相对时间是明显短板
5. **时区数据、压缩族（zstd/lz4）、BCrypt/Argon2、X.509** —— 基本需先补 native，非 .px 能绕
