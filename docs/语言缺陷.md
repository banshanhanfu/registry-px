# 语言缺陷（PuXian Language Defects）

> 本仓库在编写生态库过程中暴露的 PuXian 语言缺陷/不直观行为登记。
> **约定**：写库时遇到任何语言面问题（编译/解释不一致、原生函数语义不直观、
> 语法限制、文档与实现不符等），一律追加到本文件（新条目编号 = 当前最大 ID + 1），
> 随当次库的 commit 一起提交。修复/官方回应后可标记状态。
>
> 实测基线：PuXian 0.2.0-m197（aarch64，官方引导包；VM 轨件仅 x86_64 侧产出 ⇒ 自动落 C 轨）
> （2026-09-24 按 m197 复查）：
> - m184 已移除 PX-DEF-002/005/014（官方缺陷 200/201/202）；
> - M185–M189 官方 release 已处理并移除：PX-DEF-003（M185 新增 `unwrap_err`）、
>   018/019/020（M186 解释轨 native 透传收口）、025/026/027（M188 `.find`/`sha1`/方法面别名）、
>   012/016/017（M188 新增 `bytes_zeros`/`sha256_bytes`/`byte` 安全替代）、
>   029（M189 `bytes_get` 越界统一报 R1003）、015（M185 复测否定，三面已统一为 rune）；
> - 其余登记为官方判定的设计/文档类（状态列已更新）；
>   PX-DEF-021 在 aarch64 官方引导包解释轨仍复现（官方 M186 在 x86_64 dev 解释器复测否定，平台差异），保留登记。

## 写库时发现的其它限制（非缺陷，设计如此）

- 并发语法（spawn/chan/mutex）仅编译模式（见 PX-DEF-006）
- `let` 不可变，`var` 可变；`{}` 从 M129 起是空 dict（此前是 null）
- `join(sep, list)` **分隔符在前**（与 split 相反，易错）
- `time_format(sec, fmt)` 输出 UTC，本地时间用 `now()`
- dict 键限定 str；`d.set(k,v)` 写、`d.has(k)` 查
- `json_parse_opt` 解析外部 JSON（裸 `json_parse` 遇畸形输入会终止进程）
- 模块顶层不写 `let/var` 状态（写库规范）；有状态用显式传参/dict
- `int_to_bytes(v, size, endian, true)` 对超出**有符号** size 范围的值（如 size=4 且 v>2^31-1）返回 `null`（响亮越界，不截断）；编码负数 float 的 f32 位模式等场景须按无符号 `false` 处理

## 缺陷复现示例


```px
# PX-DEF-022 复现：list 切片浅拷贝（内层共享）
var m = [[1, 2], [3, 4]]
var cp = m[0:len(m)]
cp[0][0] = 99
print(m)   # [[99,2],[3,4]] —— 内层被改了！需手写深拷贝
```

```px
# PX-DEF-023 复现：Err 嵌套字符串化
print(Err("a: " + str(Err("b"))))   # Err(a: Err(b))
```

```px
# PX-DEF-024 复现：解释器与编译产物速度悬殊（qrcode encode 大矩阵罚分）
# px run  : ≈36s（掩码 8 × 罚分 O(n²)）
# px build产物: <1s（同源码）
```

```px
# PX-DEF-028 复现：C 风格 for(;;) 语法不支持
for (;;) {}
# E1001: 非法字符: ';'
# 无限循环须写 while true:
```

```px
# PX-DEF-030 复现：bytes_to_int 读 0xFFFFFFFF 返回无符号 4294967295（非 -1）
# 双模式一致但读 wire protocol 的 -1（NULL 长度）不可用 == -1 判断，
# 需显式传 signed=true（bytes_to_int(b, "big", true) 即得 -1），或 > 2147483647 判负
```
```px
# PX-DEF-031 复现：bytes_to_int 读 8 字节（>2^63-1）静默 wrap 为负
print(bytes_to_int(hex_to_bytes("ffffffffffffffff"), "little", false))   # -1（应为 18446744073709551615）
print(bytes_to_int(hex_to_bytes("0000000000000080"), "little", false))   # -9223372036854775808（应为 9223372036854775808）
# 绕行：32 位高低字长除法转十进制字符串（本仓 mysql/stmt.px::my_u64_dec）
```
```px
# PX-DEF-032/033 复现：base32 / hmac_sha1 缺失
print(base32_encode("abc"))      # R1001 未定义变量: 'base32_encode'
print(hmac_sha1(b"k", b"m"))     # R1001 未定义变量: 'hmac_sha1'
# 绕行：totp.px::o_b32_decode（RFC 4648 纯 .px）与 o_hmac_sha1（sha1_bytes 拼 HMAC）
```
```px
# PX-DEF-034 复现：sorted 无 key/comparator
var cmp = fn(a, b): return a > b   # 匿名函数可用
print(sorted([3, 1, 2], cmp))      # R1002: sorted 需要 1 个参数
# 绕行：natsort.px::na_sorted —— [键,下标,原值] 成对包装后走原生 sorted
```
