# 语言缺陷（PuXian Language Defects）

> 本仓库在编写生态库过程中暴露的 PuXian 语言缺陷/不直观行为登记。
> **约定**：写库时遇到任何语言面问题（编译/解释不一致、原生函数语义不直观、
> 语法限制、文档与实现不符等），一律追加到本文件（新条目编号 = 当前最大 ID + 1），
> 随当次库的 commit 一起提交。修复/官方回应后可标记状态。
>
> 实测基线：PuXian 0.2.0-m155（aarch64，C 轨 `PX_BUILD_ENGINE=c`）

## 缺陷登记

| ID | 发现库 | 描述 | 影响 | 绕行 | 状态 |
|---|---|---|---|---|---|
| PX-DEF-001 | testkit | **闭包捕获并修改外层局部变量，编译轨失败**：`main` 内 `var total=0; var t = fn(r): total += 1 ...` 在 `px build` 产物运行时报 `未定义变量: total`（解释轨正常）。与官方 CHANGELOG M158 记录缺陷 159/160（VM 轨闭包 upvalue、C 轨嵌套 def 捕获）同族 | 回调/闭包持有计数器等常见模式编译轨不可用 | 断言结果收集到 list 后统一处理；函数参数显式传状态 | 待官方修复 |
| PX-DEF-002 | cli | **`int()`/`float()` 是宽容前缀解析**：`int("abc")`=0、`int("12ab")`=12、`float("1.2.3")`=1.2（类似 C atoi，而非 Go strconv 报错） | 外部输入类型转换会静默产生错误数值 | 严格校验函数自行实现（cli 库 `cli_is_int_str`/`cli_is_float_str`） | 待官方确认是否设计如此 |
| PX-DEF-003 | decimal/cli | **Result 无 `unwrap_err()` 原语**：只有 `is_ok/is_err/unwrap`（`unwrap` 在 Err 上 panic），拿不到错误值 | 错误信息难提取 | `str(Err(...))` 剥壳（各库 `*_err_msg` helper） | 官方速查表已记录，无修复迹象 |
| PX-DEF-004 | decimal/tar | **`"s" * n` 字符串乘法双模式不一致**：`"0" * 3` 解释轨报 `R1002: 需要数值`，编译轨（m155 C 轨）实测可执行 `"x" * 1000` | 同代码双模式结果不同 | 自写 `*_repeat(s, n)` 循环拼接 | 语法未定义，双模式行为不一致 |
| PX-DEF-005 | testkit | **`mkdir()` 成功返回 `null` 而非 `true/false`**：`if mkdir(d)` 永远为假，误判失败 | 布尔判断直觉被打破 | `mkdir` 后以 `is_dir(dir)` 确认 | 待官方确认返回语义 |
| PX-DEF-006 | workerpool/testkit | **解释器（`px run`）不支持并发原语**（spawn/send/recv/select/chan/mutex）→ 报"interp 不支持通道（Mini 子集排除）" | 含并发库无法用解释器验证（文档化行为，非缺陷，但写库易踩） | 并发库标注"需编译模式"，测试用 `px build` + 产物运行 | 官方文档化（MINI_SUBSET），非 bug |
| PX-DEF-008 | validator | **`type()` 对字符串返回 `"string"` 而非 `"str"`**：`type("")` 返回 `"string"`（速查表未记录 str 的实际类型名；`type(1)` 是 `"int"`、`type([])` 是 `"list"` 等均与直觉一致） | 按 `type(v) == "string"` 判断字符串，勿用 `"str"` | 文档未覆盖，已实测 | 
| PX-DEF-009 | validator | **`regex_match(pattern, s)` 是完整匹配而非搜索**：`regex_match("a@b", "xa@by")` 返回 false（Go regexp.MatchString 语义是搜索） | 跨实现移植正则断言时需注意；需要子串匹配时 pattern 两端不要隐含 `^$` | 文档未明示，已实测 |
| PX-DEF-010 | 写库综合 | **`pbkdf2_sha256` 的 salt 参数按字符串字节处理，不自动 hex 解码**：`pbkdf2_sha256(pw, "aabb…")` 把 32 字符 ASCII 当 32 字节盐（与 Python `hashlib.pbkdf2_hmac` 传入 `bytes.fromhex` 不同）。传 `hex_to_bytes(...)`（bytes）时与标准**完全一致**（实测 64 字节输出逐字节相同） | 与标准互操作必须显式 hex_to_bytes | native 入参双形态（str/bytes）易误读 |
| PX-DEF-012 | tar | **`bytes(n)` 语义是"数字转字符串字节"而非"N 字节空 buffer"**：`bytes(10)` 返回 `"10"` 的 2 字节（bytes_len=2），非 10 字节全 0 | 造空 buffer 的直觉写法完全错误 | 循环 `bytes_concat(b, bytes("\0"))` 拼 N 次（tar_zero_buf） | 文档未明示，已实测 |
| PX-DEF-011 | datastruct | **同 priority 堆元素出队顺序双模式不一致**：`sorted([[1,"a"],[1,"a2"]])` 解释轨 pop 先出 `a2`、编译轨先出 `a`（复合 list 排序稳定/比较语义不一致） | 依赖同键稳定顺序的程序双模式结果不同 | 生态库避免依赖同优先级顺序；文档注明 | 待官方确认（sorted 复合元素语义） |
| PX-DEF-014 | glob | **`list_dir` 无安全变体（缺 `list_dir_opt`）**：对不存在的目录/非目录直接抛运行时错误终止进程（`fs: 读取目录失败`），与 `json_parse`→`json_parse_opt` 的安全变体先例不一致 | 写库时列目录前的容错流程无法用 Result 表达，进程直接退出 | 先 `file_stat(dir)` 守卫（缺失/非目录返回 null），确认 `is_dir` 再 `list_dir`；递归列举时每个子目录同样先守卫 | 待官方补 `list_dir_opt` |
| PX-DEF-015 | checksum | **`len()`/`s[i]` 按 rune、`s[a:b]` 切片按字节，双模式一致但语义混用**：`len("你好")`=2、`s[1]` 取到完整 rune "好"，而 `s[0:1]` 取到首字节 228（断开的 UTF-8 片段）。stdlib strings.px 注释称"下标为字节序下标（与切片同轴）"，实测字符串索引与切片不同轴 | 按字符串下标逐字符做字节运算（校验和/二进制 pack）会漏字节，对拍不一致 | 字节遍历一律 `bytes(s)` + `bytes_len`/`bytes_get`；按 rune 处理用 `s[i]` | 文档与实际不一致，待官方明确语义 |
| PX-DEF-007 | workerpool | **函数值作为 chan 消息元素传参可用，但注意任务 dict 键访问必须 `.has()` 守卫**：对无键 dict 直接 `d["k"]` 抛 `R1008 字典没有键`（而非返回 null/报可捕获错误） | 宽松读键模式（Python `.get` 心智）不可用 | `task.has("stop") and task["stop"]` 式守卫；或先 `d.keys()` 确认 | 官方速查表已有记载（先守卫再读），非 bug |

## 写库时发现的其它限制（非缺陷，设计如此）

- 并发语法（spawn/chan/mutex）仅编译模式（见 PX-DEF-006）
- `let` 不可变，`var` 可变；`{}` 从 M129 起是空 dict（此前是 null）
- `join(sep, list)` **分隔符在前**（与 split 相反，易错）
- `time_format(sec, fmt)` 输出 UTC，本地时间用 `now()`
- dict 键限定 str；`d.set(k,v)` 写、`d.has(k)` 查
- `json_parse_opt` 解析外部 JSON（裸 `json_parse` 遇畸形输入会终止进程）
- 模块顶层不写 `let/var` 状态（写库规范）；有状态用显式传参/dict

## 缺陷复现示例

```px
# PX-DEF-001 复现（编译模式）
def main():
    var total = 0
    var t = fn (r):
        total += 1
    t(1)
    print(total)
# px build 产物运行 → 运行时错误: 未定义变量: total
```

```px
# PX-DEF-002 复现
print(int("12ab"))   # 12（期望报错）
print(float("x"))    # 0.0（期望报错）
```
```px
# PX-DEF-014 复现：列不存在的目录 → 进程终止（非 Result）
print(list_dir("/tmp/no_such_dir_xyz"))
# 运行时错误: fs: 读取目录失败 /tmp/no_such_dir_xyz
# 绕行：先 file_stat 守卫
var st = file_stat("/tmp/no_such_dir_xyz")
if type(st) == "dict" and st["is_dir"]:
    print(list_dir("/tmp/no_such_dir_xyz"))
```

```px
# PX-DEF-015 复现：len/索引按 rune，切片按字节
var s = "你好"
print(len(s))          # 2（rune 数）
print(s[1])            # 好（完整 rune）
print(bytes_get(bytes(s[0:1]), 0))   # 228（首字节，切片按字节）
# 绕行：字节流处理用 bytes(s) + bytes_len/bytes_get
```
