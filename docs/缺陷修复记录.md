# 库缺陷修复记录（pkg-defects 修复）

> 依据 [pkg-defects.html](https://px.dzty.club/pkg-defects.html) 缺陷清单，
> 使用 PuXian v0.2.375（aarch64，C 轨）逐库校验、修复、编译验证、提交推送。
> 修复时间：2026-11-05。每个修复均经 `px build` 编译通过，逐个 commit 推送至
> `banshanhanfu/registry-px` main 分支。

## 总览

共修复 **15 个提交**，覆盖 18 处缺陷中的 15 处。未处理的 3 处：

- **pxml**：`pxml_parse` 返回 Result 但实际返回 `{ok, value}` dict — pxml 是 stdlib 内置模块，不在 registry 中，无法在此修复。
- **concurrent_map（解释轨 mutex）**：`cm_lock`/`cm_unlock` 在解释器（`px run`）中不可用 — 这是语言层面限制（PX-DEF-006），非库缺陷。
- **tar（返回值形态不一致）**：`tar_pack`/`tar_unpack` 返 Result，`tar_list_files`/`tar_has_file`/`tar_get_file_size` 返裸值 — 已在 06e5129 中增加错误检查（错误时返回安全默认值 `[]`/`false`/`-1`），改为统一 Result 会破坏现有调用方，保持当前设计。

| # | 库 | 函数 | 缺陷 | 修复 | commit |

| 2 | tar | `tar_list_files` / `tar_has_file` / `tar_get_file_size` | 对 Err 结果直接 `.unwrap()` → R1007 | 增加 `is_err()` 检查，错误时返回 `[]` / `false` / `-1` | 06e5129 |
| 3 | fsnotify | `fs_diff` | 对 Result 输入调 `.keys()` → R1007 | 自动检测并 unwrap Result 输入 | 753d334 |

| 5 | dist | `di_seed` / `di_normal_cdf` | 调不存在的 `srand` / `erf` → R1001 | 改用内建 `random_seed()`；新增 `di_erf()` Abramowitz-Stegun 近似 | 0be71e2 |
